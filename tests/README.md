# 当前验证入口

执行 `sh tests/verify_current.sh`，运行当前源码的 JUnit 测试、Android Lint、APK 构建，以及悬浮球/截图/服务集成回归。

`AnnotationOptionsTest` 验证主标注单选、辅助层独立和锁屏策略；`RowShapeTest` 验证重复组件结构识别、字体差异和间距去重。源码通过 `AnnotationPreferences`、`representativeRows`、`fontAnnotationRepresentatives` 和 `GapGeometry` 接入这些规则。

其余旧 `test_*.sh` 是历史 APK 的 smali 检查，使用固定寄存器、源行号、lambda 编号，以及旧 `typeface/grid`、三列布局。保留供历史包核查，不作为当前四列八按钮界面的验收入口，也不计入当前测试通过数。

自动检查不替代真机验收。仍需在已安装对应版本、解锁且无障碍服务绑定的设备上检查点击、滚动、锁屏恢复、截图及相册文件。

## 1.3.8 缺陷回归

- `test_capture_races.py`：抽取当前服务函数并编译，使用可控制时钟和截图回调的 JVM 平台替身，验证标注关闭重开、截图期间滚动、窗口重建。
- `test_switch_preferences.py`：运行实际 `IosSwitch` 和偏好实现，控制动画结束时机，验证视觉单选与 100,000 次固定种子偏好操作。
- `test_style_regressions.py`：运行实际行结构算法、抽取的字体缓存及标注预算函数；字体解析和标签内容由替身提供，验证完整文本/小数字号缓存键、128 条缓存上限，以及末尾差异样式保留。
- `test_feature_integration.py`：补充源码接线检查，确保采集阶段保留重复行候选，只在后续几何显示时使用结构代表标记。

这些测试验证服务逻辑与状态一致性，不代表 Android 图像采集、字体渲染或厂商后台策略已通过真机验收。

## 1.3.9 稳定性回归

- `test_capture_races.py` 增加截图失败释放刷新状态、检查模式内容变化后补拍、100 次刷新只保留最新请求、真实失败文案不误报权限，以及锁屏退出标注后解锁可重新开启。
- `test_connection_status.py` 运行实际连接状态策略，验证已开启但未绑定时的 8 秒等待期，以及实际连接恢复后的可用状态。
- 主界面新增“后台运行”入口，通过系统确认允许电池优化豁免；厂商自启动和进程冻结策略仍需在设备设置中核查。

## 1.3.10 多选

底部 8 个标注按钮和首页默认显示均为独立开关，可以全部开启或全部关闭。首次操作时将旧版 `annotType` 与辅助层状态迁移为独立布尔偏好，之后旧单选值不覆盖新状态。回归包含全部开启/关闭、100,000 次随机切换并重建偏好适配器、旧状态迁移和多个开关的动画最终状态。
